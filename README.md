# NEON SIEGE (成果物の配布)

ネオンの光彩と8-bitプロシージャルサウンドによる、レトロアーケード風トップダウン・ウェーブサバイバルシューティング。

このリポジトリは、成果物(ブラウザ版)の配布用です。ソースコードは含まれません。

## 遊ぶ

• **ブラウザ版**: https://kken0507.github.io/neon-siege-releases/  
  (PC・スマホ・タブレット。音はWeb Audio APIで生成され、最初の操作後に有効になります)
• **オフライン単一HTML版**: [Releases](https://github.com/kken0507/neon-siege-releases/releases) から `arena_wave_survival.html` をダウンロード。ブラウザでダブルクリックするだけで、ネット接続・サーバー不要でどこでもプレイできます。

## 操作

• 画面の案内は、使っている入力(キーボード・タッチ・ゲームパッド)に合わせて自動で切り替わります。

### PC (マウス＆キーボード / クラシック)
• **移動**: WASD または 矢印キー  
• **照準**: マウスカーソル (設定でクラシック操作にすると「移動方向」を向きます)  
• **発砲**: マウス左クリック (設定で「自動射撃」も可能)  
• **武器変更**: 1〜6キー、マウスホイール、画面下部の武器バー  
• **地雷設置**: Q キー  
• **バリケード設置**: E キー (向いている方向の前方に設置。敵や弾を防ぎます)  
• **リロード**: R キー  
• **ポーズ / 設定**: Esc または P キー / 画面の歯車アイコン  
• **キーコンフィグ**: 設定メニュー内の「KEY CONFIG」から任意のキーに再割り当て可能

### ゲームパッド (標準配置)
• **移動**: 左スティック / 十字キー  
• **照準**: 右スティック (右スティックを倒すと右スティック優先、マウスを動かすとマウス優先)  
• **発砲**: RT (右トリガー)、または右スティックを大きく倒す  
• **武器変更**: RB (次) / LB (前)  
• **特殊アクション**: X (地雷) / B (バリケード) / Y (リロード)  
• **決定 / 再開**: A ボタン  
• **ポーズ**: Start ボタン

### タッチ端末 (スマホ・タブレット)
• **左スティック**: 移動  
• **右スティック**: 独立照準 ＆ 倒している間自動発砲  
• **画面ボタン**: 武器選択ボタン、地雷ボタン、柵ボタン、一時停止ボタン

## ゲームモード

• **SOLO**: 1人用サバイバル。迫り来る敵を撃破し、最高スコア・最高キル・到達ウェーブを競います。  
• **CO-OP (2人協力)**: 1画面で2人同時プレイ。個別ステータス（HP・武器・弾薬・地雷・柵）、味方ダウン＆接近蘇生（2秒）、スコア・キル数・武器解放はチーム共有。  
• **VERSUS (2人対戦)**: 1画面PvPvE（先に3本先取で勝利）。初期ピストル対決、時間経過で武器クレート投下、対人ダメージ軽減補正（35%）、離れるとネオンの境界線が現れる「動的画面分割（ダイナミックスプリットスクリーン）」へ自動移行。

## ゲームシステム

• **武器 (全6種)**: ピストル(無限弾)、ショットガン、SMG(12キル解放)、グレネードランチャー(38キル解放)、アサルトライフル(70キル解放)、ロケットランチャー(120キル解放)。  
• **エネミー (全7種)**: 通常敵、高速ランナー、高耐久タンク、遠距離砲撃型、自爆特攻型、増援召喚型、大ボス(Wave 15以降の5の倍数)。  
• **コンボ ＆ 動的マグネット回収**:
  - 連続撃破でコンボ倍率が最大×5まで増加。
  - コンボ倍率に比例して物資ドロップ率が最大17%まで上昇。
  - 10 / 25 / 50コンボ達成時に確定ボーナス物資が投下。
  - コンボ数に応じてアイテム吸引（マグネット）の範囲が100pxから最大220pxへ拡大・高速化。
• **設置物**:
  - 地雷: 敵が踏むと大爆発。
  - バリケード: 敵の接近を遮り、敵弾を防ぎます(最大6個同時配置)。
  - 爆発樽: 撃つと周囲を巻き込んで誘爆。

## 性能・特徴

• **完全スタンドアロン**: 外部依存（npmパッケージ、CDN、外部画像・音声ファイル）ゼロ。  
• **プロシージャル8-bit音響合成**: Web Audio API（AudioContext）により、矩形波・三角波・ノイズ波形からオールドスクールな効果音を完全動的合成。  
• **軽量・高パフォーマンス**: 単一HTMLファイルサイズ 約111 KB。空間ハッシュグリッド（SpatialGrid）、スプライト事前キャッシュ（GlowCache）、時間分散AI（Staggered AI Ticks）により、100体以上の大群出現時も 60fps（update < 4ms）を安定維持。
